## 📋 Complete Workflow File

Save this entire block as `.github/workflows/snake.yml` in your repo (step Phase 3 above).

```yaml
# Save this file at exactly: .github/workflows/snake.yml
# Before it can run: repo Settings → Actions → General → Workflow permissions
# → "Read and write permissions" → Save. (Repo settings, not account settings.)

name: Generate Snake Animation

on:
  schedule:
    - cron: "0 */12 * * *"
  workflow_dispatch:
  push:
    branches: [main]

jobs:
  generate:
    permissions:
      contents: write
    runs-on: ubuntu-latest
    timeout-minutes: 10
    steps:
      - name: Generate snake SVGs
        uses: Platane/snk/svg-only@v3
        with:
          github_user_name: ${{ github.repository_owner }}
          # First colour in color_dots = the EMPTY cell.
          # Dark version must use a visible slate (#2d3343) — a near-black
          # empty cell disappears against GitHub's #0d1117 background.
          outputs: |
            dist/github-snake.svg?palette=github-light&color_snake=#0891B2&color_dots=#ebedf0,#a5b4fc,#818cf8,#6366f1,#0891B2
            dist/github-snake-dark.svg?palette=github-dark&color_snake=#10B981&color_dots=#2d3343,#4b5563,#7C3AED,#A78BFA,#22D3EE

      - name: Push to output branch
        uses: crazy-max/ghaction-github-pages@v3.1.0
        with:
          target_branch: output
          build_dir: dist
          commit_message: "Update snake animation [skip ci]"
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

## 🔧 Troubleshooting

| Issue | Cause | Fix |
|---|---|---|
| "API rate limit exceeded" on stats card | Using public instance | Self-host on Vercel (Phase 2 above) |
| Snake image is broken (404) | `output` branch doesn't exist yet | Run the snake Action first (Actions tab → Run workflow) |
| Snake grid invisible in dark mode | Empty-cell colour too close to GitHub's bg | Already fixed: using `#2d3343` instead of near-black |
| LinkedIn badge has no logo | Shields.io bug on custom colours | LinkedIn stays on brand blue `#0A66C2` (done) |
| Colour change invisible | CDN cache, or wrong theme | Clear cache with `?v=999`, check you're in dark mode for dark assets |
| Action fails, mentions `maxDuration` | Vercel free-tier limit | Add `"maxDuration": 10` to `vercel.json` in your fork |

## ℹ️ Notes

- **Scheduled runs pause** after ~60 days of repo inactivity. If you go quiet, the snake freezes. Push something or manually trigger it to resume.
- **Stats don't match GitHub exactly** — different date windows and cache lag. A gap of a few contributions is normal.
- **Top-languages reflects code volume**, not skill. Large repos or template CSS can dominate — you can exclude repos in the fork's settings.
- **Banner SVGs can't contain working links** — GitHub strips them. Clickable links must be badges (already done).
- The streak card, activity graph, and all badges work with zero setup — they regenerate on their own.
